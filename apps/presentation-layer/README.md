# AI-Sana — фронтенд-демо

Рабочее пространство для бизнеса: задачи слева, диалог и редактор в центре, отклики справа. На узком экране панели переключаются кнопками. Студенты видят общий каталог на всю ширину, без чата: поиск, фильтры по теме и готовности, выбор команды и свои отклики. Нажатие на строку задачи открывает сведения и форму предложения в боковой панели; закрытие сохраняет фильтры каталога.

Во всём интерфейсе используется Roboto с кириллицей через `next/font/google`, белые поверхности и нейтральный тёмный текст. Иконки рабочего пространства — `@gravity-ui/icons`; декоративные иконки сведены к минимуму. Фильтры и выбор числа участников используют стилизованный Radix Select с поддержкой клавиатуры.

В режиме бизнеса кнопка «Развернуть» оставляет только центральную панель для работы с беседой или карточкой. «Вернуть панели» восстанавливает предыдущую ширину колонок; набранный текст сохраняется при переключении этого режима. Заголовки используют жирное начертание, основной текст чата — 15 px, навигация и действия — полужирное. Прокрутка остаётся нативной, с тонкими закруглёнными полосами.

Действия «Выбрать команду» / «Отклонить» и переходы между откликами закреплены внизу панели бизнеса. Длинные описания и планы прокручиваются отдельно, а подтверждение этапа остаётся в сведениях выбранной команды.

Кнопка «Моя команда» открывает профили команд: можно сравнить навыки и интересы, выбрать другую команду, изменить текущий профиль или создать новый. Отклики и баллы связаны с ID команды и сохраняются при переключении и переименовании. Это локальное переключение демо-профилей; оно не добавляет авторизацию или реальные приглашения участников.

Реализован только frontend: без авторизации, backend, обращений к БД, настоящего AI и коннекторов. Переключатель «Бизнес / Студент» меняет режим интерфейса. Ассистент работает по локальным сценариям. Существующий стек Next.js, React, Tailwind, shadcn/ui и AI Elements сохранён.

Все изменения живут в памяти вкладки. Обновление страницы или «Демо → Начать демо заново» возвращает исходные данные. В демо есть 6 опубликованных задач, 6 черновиков, 6 команд и 7 откликов; компании, участники и сведения вымышлены. Ссылки на прототипы в исходных данных ведут на `example.com` и служат примерами.

## Запуск

Нужны Bun 1.4.2 и Node.js >=24. Из корня репозитория:

```sh
bun install --frozen-lockfile
cd apps/presentation-layer
bun run dev
```

Откройте [localhost:3000](http://localhost:3000). Для этого UI не нужны Docker, `start.sh`, PostgreSQL, Mastra или ключи внешних сервисов.

## Показ за пять минут

1. В режиме бизнеса создайте черновик и опишите проблему своими словами. Ассистент покажет три уточняющих вопроса.
2. Нажмите на вопрос и отправьте ответ. Текст без изменений попадёт в выбранное поле карточки; неподтверждённый ответ пока не повышает оценку. Повторите для остальных вопросов.
3. Откройте «Карточка задачи», проверьте формулировки и отметьте подтверждение заполненных полей. Посмотрите предварительную оценку и нажмите «Подтвердить и опубликовать».
4. Переключитесь в режим студента. Найдите опубликованную задачу, выберите команду и нажмите «Предложить решение». Заполните идею, план, срок и ссылку на прототип, например `https://example.com/demo/my-prototype`, затем отправьте отклик.
5. Вернитесь в режим бизнеса. Отклик появится справа: рассмотрите его, выберите команду или отклоните предложение. Можно отменить решение, выбрать несколько команд или не выбирать никого — автоматического назначения нет.
6. Для выбранной команды вручную подтвердите этап. Команда получает 10 демонстрационных баллов один раз за этот отклик; повторное подтверждение не начисляет их снова. В режиме студента проверьте статус и баллы.

Опубликованные задачи доступны для отклика при любой готовности. Низкая оценка помогает увидеть пробелы, но не блокирует публикацию или участие. Публикация и изменение публичной карточки требуют подтверждения текста бизнесом.

## Готовность задачи

Баллы начисляются только за непустые подтверждённые поля. При изменении поля его нужно подтвердить заново. Неизменённые подтверждённые поля сохраняют баллы.

| Категория              |                                Максимум |
| ---------------------- | --------------------------------------: |
| Контекст и потребность |               20 — по 10 за каждое поле |
| Данные и материалы     |                                      20 |
| Ожидаемый результат    |                                      15 |
| Критерии успеха        |                                      15 |
| Ограничения            |                                      10 |
| Пользователи           |                                      10 |
| Связь с бизнесом       | 10 — контакт 5, формат взаимодействия 5 |
| **Итого**              |                                 **100** |

Первая опубликованная задача «Снизить списания в пекарне» имеет 70 баллов и три отклика. В каталоге есть опубликованный пример с 25 баллами для проверки доступности задач с неполным брифом.

## Где находится код

| Модуль                         | Ответственность                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------- |
| `src/entities/workspace`       | Типы, расчёт готовности, вопросы, демонстрационные данные и тесты модели        |
| `src/features/task-editor`     | Редактирование, подтверждение полей и публикация карточки                       |
| `src/features/task-inspector`  | Просмотр откликов, форма предложения, выбор команды и подтверждение этапа       |
| `src/features/student-catalog` | Общий каталог, поиск, фильтры, выбор команды и панель сведений                  |
| `src/features/team-picker`     | Просмотр, выбор, создание и редактирование профиля команды                      |
| `src/_pages/workspace`         | Локальное состояние, роли, панели бизнеса, диалог, создание задачи и сброс демо |

Публичные импорты проходят через `index.ts` соответствующего модуля. Все UI callbacks сейчас изменяют локальное состояние страницы.

## Будущий API: черновик контракта

Следующие маршруты **не реализованы**. Таблица предназначена для будущей интеграции существующих UI callbacks.

| Метод и маршрут                      | Назначение                                                 |
| ------------------------------------ | ---------------------------------------------------------- |
| `GET /api/tasks`                     | Список задач для каталога и рабочего пространства          |
| `POST /api/tasks`                    | Создать черновик из описания                               |
| `PATCH /api/tasks/:id`               | Обновить поля и сведения об их подтверждении               |
| `POST /api/tasks/:id/publish`        | Опубликовать подтверждённую карточку                       |
| `POST /api/tasks/:id/proposals`      | Отправить предложение команды                              |
| `PATCH /api/proposals/:id`           | Выбрать, отклонить или вернуть отклик к рассмотрению       |
| `POST /api/proposals/:id/milestones` | Подтвердить этап с защитой от повторного начисления баллов |

При интеграции сохранить границы из `docs/ARCHITECTURE.md` в корне репозитория: бизнес-данные UI — `nextjs_db` через существующий Drizzle; AI — только `ai-logic-layer`/Mastra через `@mastra/client-js` и `MASTRA_API_URL`. Эта передача описывает дальнейшую работу и не добавляет сервисы или подключения.

## Проверка

Команды из `apps/presentation-layer`:

```sh
bun run check-types
bun run build
bun run lint -- src/_pages/workspace src/features/student-catalog src/features/team-picker src/features/task-editor src/features/task-inspector src/entities/workspace
bun test src/entities/workspace/model.test.ts
```

Это команды для воспроизведения проверок, а не отметка об их последнем успешном запуске.

Короткая проверка UI:

- В режиме бизнеса на широком экране видны три панели; на узком доступны задачи, чат и отклики через переключатели.
- В режиме студента виден каталог всех опубликованных задач по убыванию готовности, включая 25-балльную карточку. Чата нет; поиск, фильтры и «Мои отклики» работают вместе. Сведения и отклик открываются в боковой панели.
- Новый черновик показывает три вопроса; ответ сохраняется именно в выбранное поле.
- Без подтверждения поля не добавляют баллы, публичные изменения не сохраняются без проверки текста.
- Опубликованная задача с низкой оценкой доступна студенту; отправленный отклик виден бизнесу.
- Выбор, отклонение и отмена решения отражаются у студента; подтверждённый этап даёт ровно 10 баллов.
- Сброс демо очищает изменения, беседы и незавершённый ввод. Основной сценарий не вызывает внешние API.
- В «Моя команда» смена профиля обновляет «Мои отклики» и баллы. Создание выбирает новую команду; редактирование имени сохраняет её отклики. Форма требует название и 3–5 участников.
