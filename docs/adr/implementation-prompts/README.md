# Параллельная реализация ADR

Запускайте каждый промпт в отдельном чате и worktree. Все worktree создаются от одной и той же базовой ветки; агенты работают независимо и не ждут друг друга. После завершения интегрируйте изменения по порядку ниже, разрешая конфликты на общей интеграционной ветке.

Порядок интеграции: 001 → 002 → 003 → 004 → 005 → 006 → 007 → 008 → 009 → 010. У ADR-004–008 возможны пересечения схемы БД и use-case; у ADR-008/009 — общие границы доступа и API. Сохраняйте миграции и поведение каждого изменения, объединяйте дублирующиеся правки и запускайте проверки после каждого шага. Не заменяйте целиком файлы одной ветки файлами другой.

ADR-001 принят; ADR-002–010 имеют статус Proposed.
